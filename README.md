# cristianrubioa.github.io

Personal site and portfolio of **Cristian F. Rubio A.** — live at [crubio.fyi](https://crubio.fyi).

Built on [Academic Pages](https://github.com/academicpages/academicpages.github.io) (Jekyll + Minimal Mistakes).

## Running locally

1. Install Ruby, Bundler, and Node.js.
2. `bundle install` (use `bundle config set --local path 'vendor/bundle'` if you hit permission errors).
3. `bundle exec jekyll serve -l -H localhost` and open `localhost:4000`.

### Using Docker

```bash
chmod -R 777 .
docker compose up
```

Then open `localhost:4000`.
